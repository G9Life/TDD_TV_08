## 1. 보고서 개요

본 보고서는 TDD TV 셋탑박스 채널 Controller 모듈의 `README.md` 요구사항을 C++17 구현 및 Google Test 관점에서 재정리한 결과이다. 분석 대상은 리모컨 입력을 받아 채널 상태를 관리하고, 외부 `Tuner` 인터페이스를 통해 실제 채널 변경을 위임하는 Controller 모듈이다.

### 1.1 분석 범위

- TDD_TV 기본 요구사항 4개 항목
- TDD practice 요구사항 6개 항목
- 채널 번호 입력 규칙 (선행 0, 최소/최대, 음수 예외)
- Google Test 기준 테스트 시나리오

### 1.2 구현 전제

- `Tuner`는 업체 제공 인터페이스이며, Controller 테스트 시 Fake 또는 Mock으로 대체한다.
- Tuner API: `seekCH()`, `setCH(ch)`, `getCurrentCH()`
- 일반 채널 범위: **0 ~ 99**

## 3. 번호 입력 시 최초 0일 경우 주의점

1. 채널 번호는 문자열 기반 입력 버퍼로 관리하는 것이 안전하다. `0`, `7` 입력은 정수 `07`이 아니라 `"0" + "7"` 조합으로 해석한 뒤 십진수 7번 채널로 확정한다.
2. C++ 구현에서 `07` 같은 리터럴 표현을 사용하면 구버전 문법에서는 8진수 리터럴로 해석될 수 있으므로, 테스트 데이터와 구현 모두 정수 리터럴 `07`을 사용하지 않는다.
3. 최초 입력이 `0`이고 다음 입력이 숫자이면 두 자리 입력으로 간주하되, 확정 채널은 선행 0을 제거한 십진수 값이다.
4. 최초 입력이 `0`이고 `확인`을 누르면 0번 채널로 확정하는 규칙이 자연스럽다.
5. 최초 입력이 `0`인 상태에서 숫자나 `확인`이 아닌 기능 버튼을 누르면 보류 중인 숫자 입력은 무효화한다.

## 4. 최소 및 최대 입력 가능한 채널 번호

| 구분 | 값 | 비고 |
|---|---:|---|
| 최소 채널 번호 | 0 | 일반 채널 하한 |
| 최대 채널 번호 | 99 | 일반 채널 상한 |
| 범위 불변식 | `0 <= ch <= 99` | Controller 내부 상수로 고정 권장 |

**구현 권장 상수**

```cpp
constexpr int MIN_CHANNEL = 0;
constexpr int MAX_CHANNEL = 99;
```

**추가 규칙**

1. 숫자 버튼 조합으로 만들 수 있는 유효 채널은 0부터 99까지이다.
2. 두 자리 숫자가 완성되면 즉시 채널을 확정하므로, 리모컨 숫자 입력만으로 100 이상의 채널을 확정하지 않는다.

## 5. 채널 번호 음수값 입력 시 예외처리

| 조건 | 처리 방침 |
|---|---|
| `ch < 0` | `std::invalid_argument` 발생, `Tuner::setCH()` 미호출 |
| `ch > 99` | 동일하게 잘못된 입력으로 처리 |
| 예외 발생 시 | 현재 채널, 선호 채널 목록, 검색 채널 목록, 숫자 입력 버퍼 변경 없음 |

**QA 관점 정리**

1. 리모컨 숫자 버튼만으로는 음수 채널이 만들어질 수 없다.
2. Controller의 public API가 정수 채널 번호를 직접 받는 경우, 음수 및 범위 초과 입력에 대한 방어 로직이 필요하다.
3. 채널 번호는 **0부터 양수만** 허용하며, 유효 범위는 **0 ~ 99**이다.
