## 1. 보고서 개요

본 보고서는 TDD TV 프로젝트의 `TVController` 모듈에 대한 **Google Test `TEST_F` 기반 단위 테스트 계획**을 정의한다. 요구사항 분석 보고서(RPT-01) 및 `README.md`의 TDD practice 6개 항목을 검증 가능한 테스트 케이스로 분해하고, 채널 번호 **0~99** 경계값·예외·특이 시나리오를 목록화하며, **라인 커버리지 90% 이상** 달성을 위한 gcov/lcov 측정·개선 전략을 제시한다.

### 1.1 계획 범위

| 구분 | 포함 | 제외 |
|------|------|------|
| SUT | `TVController::pushButton` 및 private 로직의 **간접** 검증 | — |
| 의존성 | `Tuner` Mock/Fake (호출·인자·반환) | Tuner 업체 실구현 |
| 테스트 스타일 | `TEST_F(TVControllerTest, …)` 중심, 필요 시 `TEST_P` | E2E, UI, 센서 원천 파싱(미구현 시) |
| 커버리지 | `src/TVController.cpp` | `test/*`, googletest, `remoteKey.h` |

### 1.2 채널 도메인

## 2. 테스트 인프라

### 2.1 프레임워크 및 빌드

- **Google Test** + **Google Mock** (CMake `FetchContent`, googletest v1.14.0)
- 실행 타깃: `TVControllerTest` (`test/TVControllerTest.cpp` + `src/TVController.cpp`)
- 참고: `TunerTest` (`test/TunerTest.cpp`)는 Mock 사용 패턴·Tuner 계약 학습용이며, 커버리지 목표는 **`TVController` 소스**에 둔다.

### 2.2 공통 Fixture (`TEST_F`)

```cpp
class TVControllerTest : public ::testing::Test {
protected:
    MockTunerForController mockTuner;
    std::unique_ptr<TVController> controller;

    void SetUp() override {
        ON_CALL(mockTuner, getCurrentCH())
            .WillByDefault(Return("6"));
        controller = std::make_unique<TVController>(&mockTuner);
    }

    void press(remoteKey key) { controller->pushButton(key); }
    void pressDigits(std::initializer_list<remoteKey> keys) {
        for (remoteKey k : keys) press(k);
    }
};
```

**검증 원칙**

- `getCurrentCH()`: 테스트별 `EXPECT_CALL`로 초기 채널 명시
- `setCH(const std::string&)`: 기대 채널·호출 횟수 검증
- public getter 부재 → **Tuner 호출 결과**와 **연속 입력 후 동작**으로 내부 상태(선호/검색 목록) 간접 검증

### 2.3 명명 규칙

`TEST_F(TVControllerTest, <기능>_<조건>_<기대결과>)`

요구사항 분석서 §5 Google Test 시나리오와 **이름 1:1 매핑** (예: `DigitThenConfirm_ChangesToSingleDigitChannel`).

## 6. 커버리지 목표 및 gcov/lcov 전략

### 6.1 목표 지표

| 지표 | 목표 | 측정 대상 |
|------|------|-----------|
| 라인 커버리지 | **≥ 90%** | `src/TVController.cpp` |
| 함수 커버리지 | **≥ 95%** | 동일 |
| 분기 커버리지 | **≥ 85%** (권장) | `pushButton`, Up/Down, Search |
| PR 게이트 | 라인 **≥ 88%** | CI 하한 |

**lcov 제외:** `test/*`, `build/*`, googletest, gmock, `remoteKey.h`

### 6.2 CMake 커버리지 옵션 (권장)

```cmake
option(ENABLE_COVERAGE "Build with coverage" OFF)
if(ENABLE_COVERAGE)
    if(CMAKE_CXX_COMPILER_ID MATCHES "GNU|Clang")
        add_compile_options(--coverage -O0 -g)
        add_link_options(--coverage)
    endif()
endif()
```

```bash
cmake -S . -B build-cov -DENABLE_COVERAGE=ON
cmake --build build-cov
ctest --test-dir build-cov --output-on-failure
```

### 6.3 lcov 수집·리포트

```bash
lcov --capture --directory build-cov --output-file coverage.info
lcov --remove coverage.info '/usr/*' '*/test/*' '*/googletest/*' '*/gmock/*' \
     --output-file coverage.filtered.info
lcov --list coverage.filtered.info
genhtml coverage.filtered.info --output-directory build-cov/coverage-html
```

Windows: **MSYS2/MinGW + lcov** 또는 **WSL** 권장. MSVC는 OpenCppCoverage 등 별도 도구.
